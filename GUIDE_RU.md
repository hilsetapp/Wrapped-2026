# 📘 GitHub Wrapped 2026 — инструкция «для чайников»

Пошагово, без умных слов. Что это, как пользоваться и как устроено внутри.

---

## 1. Что это вообще такое?

Маленький сайт, который делает **«итоги года» по твоему GitHub** — как Spotify Wrapped,
но для кода: красивые анимированные слайды со статистикой и постер-картинкой на память.

**Живой адрес:** https://hilsetapp.github.io/wrapped-2026/
(сайт хостится на GitHub Pages — это бесплатно и без рекламы).

## 2. Как пользоваться (3 шага)

1. Открой сайт в браузере.
2. Введи ник GitHub — свой или любой чужой (логиниться **не нужно**, сайту не нужен доступ к аккаунту).
3. Нажми **«Wrap my year ✨»** → смотри историю (слайды листаются сами или по тапу по краям экрана).

На последнем слайде:
- **⬇️ Download poster PNG** — скачать постер (квадрат 1080×1080, идеально для поста);
- **𝕏 Share / ✈️ Telegram / 🔗 Copy** — поделиться ссылкой;
- **↻ make yours** — начать заново с другим ником.

### Быстрые мелочи
- **Переключатель EN/RU** — справа вверху на главной и слева вверху внутри истории; переводится всё: слайды, архетипы («Сова», «AI-натив», «Воин выходного дня»…), и даже скачанный постер.
- Горячие клавиши на компьютере: **← / →** — слайды, **Esc** — назад на главную.
- Зажми палец/мышь на экране — история **встанет на паузу**.
- Ссылка вида `…/wrapped-2026/?u=torvalds` запускает историю сразу для ника `torvalds` — удобно присылать знакомым.

## 3. Это безопасно? Где мои данные?

- Сайт **не просит пароль и не требует входа**. Он использует только публичные данные GitHub —
  те же, что видны любому на странице твоего профиля.
- Вся логика крутится **внутри твоего браузера**. У сайта нет своего сервера: запросы идут
  напрямую к GitHub, ответ рисуется на экран. Результат на 15 минут копится в `localStorage`
  твоего браузера — и больше нигде.
- Хочешь убедиться — нажми F12 → вкладка **Network**: там только запросы к `api.github.com`
  и `github-contributions-api.jogruber.de`.

## 4. Почему сайт иногда «не находит» цифры?

| Сообщение | Что случилось | Что делать |
|---|---|---|
| `Couldn't find @...` | Ник написан с опечаткой | Проверь имя на github.com |
| `GitHub's free API limit is hit` | GitHub даёт 60 запросов/час с одного IP | Подожди ~15–60 минут |
| `Something went wrong...` | Нет сети или API лежит | Проверь интернет, обнови страницу |

Если слайда с «раскраской года» нет — не беда: это сторонний API графы вкладов
временно не ответил; остальное соберётся.

## 5. Как устроен код (если любопытно)

Всё — на простом HTML/CSS/JS, без фреймворков и сборки. Четыре файла-скрипта:

- `js/github.js` — скачивает данные (профиль, репозитории, графу, PR, события) и кэширует.
- `js/stats.js` — считает статистику: серии дней, языки, «ночной» процент и выбирает **архетип**.
- `js/poster.js` — рисует постер на `<canvas>` и сохраняет его как PNG.
- `js/app.js` — показывает слайды, управляет автопроигрыванием и шерингом.

Хочешь добавить свой архетип? Открой `js/stats.js`, найди блок `const arches = []` —
добавь своё правило по образцу, перезагрузи страницу. Вот и весь механизм.
