## ✨ Что это?

Spotify Wrapped - но для GitHub. Вводишь любой ник и получаешь **анимированную историю**
(слайды-«сторис», как в Instagram) про 2026 год:

- 📊 **главные цифры** - контрибуции, пул-реквесты, новые репозитории, заработанные звёзды
- 🎨 **топ языков** с анимированными барами
- 🟩 **твоя графа вкладов** - самая длинная серия дней и самый бешеный день года
- 🦉 **твой ритм кодинга** - сова или жаворонок? кодируешь по выходным?
- 🃏 **твой архетип** - *Сова, AI-натив, Воин выходного дня, Художник графы, Полиглот…*
- 📦 **репозитории года** + твой AI-след эпохи 🤖
- 🌍 **Русский & English** - переключение в один тап, работает даже посреди истории, включая постер

…и всё заканчивается **постером PNG 1080×1350**, который можно скачать и запостить куда угодно.

## 🚀 Попробовать за 10 секунд

> **https://hilsetapp.github.io/Wrapped-2026/**

1. Открой ссылку.
2. Введи любой ник на GitHub - свой, друга, `torvalds`…
3. Пролистай историю, скачай постер, поделись.

Без аккаунта, без OAuth, без «Войдите через GitHub». Ничего устанавливать не нужно -
сервера не существует в принципе.

## 🔒 Приватность - это фича

Всё работает **на 100% у тебя в браузере**. Страница делает несколько `fetch`-запросов
напрямую с твоего устройства к бесплатным публичным API - и всё:

- **нет бэкенда**, нет базы, нет аналитики, нет куки;
- результат кэшируется в твоём собственном `localStorage` на 15 минут (обновление - мгновенно);
- постер рисует `<canvas>` твоего браузера - он никуда не отправляется.

Можешь проверить сам: DevTools → Network. Увидишь только запросы к
`api.github.com` и API графы вкладов, и все инициирует твой браузер.

## 🛠 Как это устроено

Данные приходят с публичных API без авторизации (60 запросов GitHub API в час
с одного IP посетителя - приложение вежливо обрабатывает лимит):

| Что | Откуда |
|---|---|
| Профиль и аватар | `api.github.com/users/{u}` |
| Репозитории, языки, звёзды, AI-след | `api.github.com/users/{u}/repos` |
| Графа вкладов за год и серии | `github-contributions-api.jogruber.de` |
| Счётчики PR / issues за 2026 | `api.github.com/search/issues` |
| Ритм кодинга (процент ночного) | `api.github.com/users/{u}/events/public` |

Если один из источников недоступен - пропускается его слайд, а не вся история.

### Стек (нарочно скучный)

Чистые **HTML + CSS + JavaScript. Ноль зависимостей. Без сборки.**
Можно склонировать репозиторий и просто дважды кликнуть `index.html` - работает.

```
wrapped-2026/
├── index.html          # лендинг + окно истории
├── styles.css          # нео-брутальный «зин»: бумага, чернила, жёсткие тени
├── js/
│   ├── i18n.js         # строки RU/EN для лендинга, истории и постера
│   ├── github.js       # слой данных (fetch + кэш в localStorage)
│   ├── stats.js        # сырьё → серии, языки, архетипы
│   ├── poster.js       # рисует PNG 1080×1350 на canvas
│   ├── vendor/         # vendored qrcode-generator (MIT) для QR на постере
│   └── app.js          # движок историй: слайды, автоплей, шеринг
└── assets/             # логотип и og-баннер
```

### Запустить локально

```bash
git clone https://github.com/hilsetapp/Wrapped-2026.git
cd wrapped-2026
# вариант 1: просто открыть index.html в браузере ✅
# вариант 2: через сервер (удобно тестировать с телефона в той же Wi-Fi):
python3 -m http.server 8000
```

## 🎁 Зачем делиться постером?

Вотермарка на каждом постере - это виральная петля: друзья видят твой результат →
вводят свой ник → постят собственный постер. Вся магия Wrapped, теперь для разработчиков.
